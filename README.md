# RKSP Exam Project  
Микросервисная система обработки событий покупок

## Описание проекта
Проект представляет собой микросервисную систему, состоящую из двух Spring Boot сервисов и инфраструктурных компонентов.

Система предназначена для:
- приёма событий покупок,
- передачи событий через брокер сообщений,
- сохранения и последующей обработки данных в базах данных.

Архитектура построена по принципам микросервисов и асинхронного взаимодействия.

---

## Архитектура

### Сервисы
- **Ingest Service**
  - принимает входящие события (HTTP)
  - публикует сообщения в RabbitMQ

- **Processor Service**
  - подписывается на очередь RabbitMQ
  - сохраняет данные в PostgreSQL
  - агрегирует / обрабатывает данные
  - записывает результаты в ClickHouse

### Инфраструктура
- **RabbitMQ** — брокер сообщений
- **PostgreSQL** — реляционное хранилище
- **ClickHouse** — аналитическая БД
- **Docker + Docker Compose** — оркестрация

⚠️ В локальной сети используется SSL MITM,
поэтому сборка производится в нормальной среде
(Linux / домашняя сеть / CI).
В моей сети режется Maven Central,
проект корректно собирается в нормальной среде
